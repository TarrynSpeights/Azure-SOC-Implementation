# Azure SOC Implementation

## Overview

This project demonstrates the deployment of a cloud based Security Operations Center using Microsoft Azure and Microsoft Sentinel. The environment is designed to collect Windows security logs, detect suspicious activity, investigate security incidents, and visualize security events.

## Project Objectives

1. Deploy a Windows virtual machine in Microsoft Azure.
2. Configure a Log Analytics Workspace.
3. Enable Microsoft Sentinel.
4. Collect Windows security event logs.
5. Create Kusto Query Language queries.
6. Detect suspicious authentication activity.
7. Investigate security incidents.
8. Create dashboards and workbooks.
9. Document findings and remediation recommendations.
